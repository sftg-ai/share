# СП «ВИ-МЕНС» ООО (`vimens.by`) — Пакет из 5 ИИ-агентов для металлообработки и станков

> [!IMPORTANT]
> **Технический вердикт:** Все 5 предложенных сценариев полностью реализуемы и интегрируются с Битрикс24 / 1С. Рекомендуется начинать с пилота на 1–2 самых быстрых по окупаемости агентах (Агент повторных продаж пил/ЗиП или Сервисный диспетчер).

---

## Готовый текст для отправки клиенту («ВИ-МЕНС»)

> [!TIP]
> Нажми на иконку **Copy** в правом верхнем углу серого блока ниже, чтобы скопировать текст.

```text
Предложения по ИИ-автоматизации отдела продаж и сервиса для компании «ВИ-МЕНС» (vimens.by):

1. Пресейл-агент для менеджера
Собирает открытые сведения о предприятии-клиенте и готовит краткую справку в Битрикс24 перед звонком: профиль производства, станочный парк, вероятные потребности в оборудовании/инструменте и проверочные вопросы для разговора.

2. Помощник по техническому подбору оборудования
По заявке клиента уточняет обрабатываемый материал, сечение заготовки, объёмы и операции, после чего предлагает менеджеру подходящие категории и модели ленточнопильных станков и полотен из каталога ВИ-МЕНС.

3. Сервисный диспетчер
Принимает описание неисправности, фото шильдика и модель станка в Telegram/мессенджере, проводит первичную квалификацию по мануалам, собирает данные для выездного инженера в Битрикс24 и помогает определить срочность обращения.

4. Агент повторных продаж расходников и оснастки
Анализирует историю отгрузок и расхода и заранее напоминает менеджеру в Битрикс24, когда конкретному заводу потребуются ленточные пилы, СОЖ, инструмент или ЗиП, не позволяя клиенту уйти к конкурентам.

5. Помощник по подготовке коммерческого предложения
Собирает из параметров заявки, каталога ВИ-МЕНС и условий поставки готовый черновик коммерческого предложения для финальной проверки менеджером за 2 минуты вместо нескольких часов.
```
